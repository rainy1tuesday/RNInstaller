# Raynet Installer Framework 0.4 — Native Help Fix 3

Logging layout simplified.

For `MyMainScript.ps1`, all logs generated by that package now go directly to:

`<LogRoot>\MyMainScript\`

Example:

- `MyMainScript_Install.log`
- `Stop DSM Core Service_Install.log`
- `Install MyApp_Install.log`
- `Install MyApp_Install_MSI.log`

There is no `Components` subfolder and no per-component folder layer.

The package log folder is derived from the main script filename, not `$AppName`.

All generated log folder/file names are sanitized through
`ConvertTo-RaynetSafePathName`, which removes/replaces characters that Windows
cannot use in file or directory names.
